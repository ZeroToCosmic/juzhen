# ADR-0007: 人工点选与严格定位
## 状态
Accepted (Retrospective)
## 当前事实
V2由用户在真实页面点选元素，保存多组Locator；运行时要求唯一、可见、可操作，失败即停止受影响Profile。
## 决定
不以LLM语义猜测或页面坐标替代用户目标；不在运行中自动修复并继续副作用。
## 代码与历史证据
`execution_v2/picker.py`、`locator.py`、`elements.py`及V2设计规格。
## 为什么
TikTok DOM动态且语义/位置可能歧义；错误点击或提交的代价高于人工重新点选。
## 后果
行为可审计、fail-closed；页面改版时需要人工维护元素。
## 已知限制
无法保证选择器永久稳定；点选器必须支持先交互展开次级区域。
## 后续变更条件
引入自动修复必须证明不会改变目标身份，并单独审批副作用策略。

# 10 项架构改动 × 里程碑映射

**日期**：2026-08-11 | **对象**：PRD v3 迭代规划的直接输入
**前置**：`docs/架构改进方案-四大量化瓶颈.md`（10 项改动定义）

## 前置设计原则（防返工）

**凡影响表结构、API 契约、消息协议的改动，在对应里程碑的"设计期"定契约，实现随里程碑落地**——规模设计前置，不允许"先简单实现、后改契约"。

## 映射表

| # | 改动 | 里程碑 | 范围 | 依赖 | 验证 |
|---|---|---|---|---|---|
| 9 | 心跳写分离（追加表/Redis 缓冲） | **M1** | 设备模型设计期定心跳表结构（追加式 `device_heartbeats` 或 Redis 缓冲）；devices 主行状态聚合刷新 | — | S2 心跳写不阻塞主表 |
| 10 | max_accounts 按磁盘动态计算 | **M1 基础 / M3 完善** | M1：设备模型含 `disk_free_gb` 字段 + 心跳上报 + 分配器把磁盘纳入候选；M3：S2 实测数据回填系数 | 依赖 #9（心跳字段） | S2 实测单台容量 → 系数校准 |
| 2 | 独立 leases 表 + 部分索引 | **M1 建模 / M2 实现** | M1 模型期建 `leases` 表（subtask_id 唯一 + generation/owner/expires）+ 部分索引；M2 租约实现直接用独立表（不做内嵌再抽离） | — | M2 租约测试 + S3 回收器时延 |
| 3 | 任务拆解异步化（job + 分片 + 进度） | **M2** | 任务创建=校验+落库+202；拆解后台 job 按片（1,000-5,000/片）流式 INSERT + 进度字段 | — | 15 万账号拆解 <2min、内存 <1GB |
| 4 | DAG 短路 + 连通分量 + 边上限 | **M2** | 无依赖短路、连通分量内检测、依赖边数/账号数上限校验 | 与 #3 同文件同迭代 | 10 万节点无环/环/超限用例 |
| 1 | 续租不 bump revision | **M2** | `renew_lease` 仅更新 last_progress_at（revision 只随状态迁移变） | #2（独立表） | 续租 SQL 不触发索引写 |
| 8 | 看门狗连续超时判定 | **M2** | Agent AdsPower 网关：强杀=连续 N 次超时 + 持续窗口；单次超时仅重试 | — | 模拟 API 慢响应 → 不误杀 |
| 5 | WS 事件聚合器 + 订阅过滤 | **M3** | central 聚合（500ms 窗口合并）+ `?types=` 订阅参数 + 无订阅者不发布 | — | S3 出口速率 ≤50 条/s |
| 6 | 前端增量渲染 + rAF 节流 | **M3** | bcs.js 全量刷新 → 增量更新 + rAF 批处理 + 30s 校准 | #5（事件驱动） | 30 分钟内存曲线稳定 |
| 7 | Agent 缓存清理 + 动态背压 | **M3** | 每日低峰清理超阈值 Profile 缓存；API 响应均值超阈值→降并发（3→2→1）回升 | Agent 稳定（M2 后） | 缓存控制 ≤200MB/Profile；慢 API 不误杀 |

## 每里程碑的规模验证点

| 里程碑 | 验证（规模相关） |
|---|---|
| M1 | 心跳写分离生效（S2 准备：fake-agent 模拟器第一版，50 设备） |
| M2 | 15 万账号拆解专项；租约独立表回归；S2 压测（50 设备/15k 账号，PG） |
| M3 | WS 聚合/订阅压测；前端内存稳定性；Agent 缓存/背压实测；S3 压测（500 设备/150k 账号） |
| M4 | 混沌 + S4 扩展性（1,000+ 设备）；多租户激活后按租户分片压测 |

## 依赖关系图

```
M1: #9(心跳分离) ──> #10(磁盘字段/分配) ; #2(leases 建模)
      │
M2: #2(leases 实现) ──> #1(续租优化)
    #3(拆解异步) + #4(DAG 优化)   ; #8(看门狗)
      │
M3: #5(WS 聚合) ──> #6(前端增量)
    #7(缓存/背压，依赖 Agent 稳定)
      │
M4: 混沌压测 + 扩展性（依赖全部前置）
```

## 关键决策记录

| 项 | 决策 |
|---|---|
| leases 表时机 | M1 建模、M2 实现（不做内嵌再抽离） |
| 拆解异步 | M2 直接异步分片（不做同步版） |
| WS 协议 | M3 定 `types` 订阅参数（前端按需） |
| max_accounts | M1 磁盘字段就位；系数 M3 用 S2 实测校准 |
| 单台容量现实 | S2 实测前不承诺 300/台；PRD v3 按实测值定目标 |

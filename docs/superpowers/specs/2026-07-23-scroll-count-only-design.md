# 滚动动作仅配置滚轮次数设计

日期：2026-07-23

## 目标

向上滚动和向下滚动只让用户配置滚轮事件次数及事件间隔，不再暴露浏览器 `wheel` 事件的像素位移参数。

## 已确认行为

- 移除滚动编辑器中的“单次滚动距离”字段。
- 保留“最小滚轮次数”“最大滚轮次数”“最小间隔秒数”“最大间隔秒数”。
- 每次执行时，在最小/最大滚轮次数之间随机抽取正整数 `N`。
- 执行器准确调用 `page.mouse.wheel()` 共 `N` 次。
- 每次事件固定使用纵向增量 `120`：向下为 `+120`，向上为 `-120`。
- 相邻事件之间继续按配置的最小/最大间隔随机等待。

## 兼容与持久化

- 配置结构暂时保留 `distance` 字段，以兼容已经保存的策略和旧版本数据。
- 读取、编辑或保存旧策略时，任何旧 `distance` 值统一规范化为 `120`。
- 新增滚动动作的默认 `distance` 为 `120`。
- 前端不显示或要求输入 `distance`。
- 保存和刷新页面后，滚轮次数及间隔继续从现有持久化配置恢复，不会丢失。
- 隐藏的旧 `burst_count` 继续固定为 `[1, 1]`，不改变每个滚轮次数对应一个 wheel 事件的语义。

## 实现边界

- 在共享配置模块定义单一常量 `SCROLL_WHEEL_DELTA = 120`，校验和执行统一引用。
- 前端滚动参数解析不再读取 `distance`，直接写入兼容值 `120`。
- 后端规范化滚动动作时忽略传入的旧距离并输出 `120`。
- 执行层不信任配置中的旧距离，始终使用固定值 `120`。
- 不修改移动、点击、键盘输入、等待或录制轨迹功能。

## 测试

1. 滚动编辑器只显示四个次数/间隔字段，不显示距离字段。
2. 前端保存滚动动作时，不需要距离输入且输出兼容值 `120`。
3. 旧策略中的 `distance: 600` 能正常读取，并在规范化/保存后变为 `120`。
4. 最小/最大次数必须是有序正整数。
5. 固定随机数后，执行器准确产生 `N` 个 wheel 事件。
6. 每个向下事件为 `+120`，每个向上事件为 `-120`。
7. 刷新或重启后的次数、间隔和兼容距离保持正确。

## 非目标

- 不模拟物理鼠标驱动层的硬件齿格。
- 不允许用户重新配置单次像素位移。
- 不改变滚动次数的随机范围语义。
